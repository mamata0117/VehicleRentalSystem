Vehicle Rental System 
Hello everyone,This is a simple console based Vehicle Rental System built using C++.This project was developed to practice Object Oriented Programming concepts, file handling, and data structures by simulating a realworld vehicle rental service.The system allows customers to rent vehicles, drivers to manage bookings, and admins to control vehicles and booking operations.

Features
Customer
Register and login
View available vehicles
Book passenger or goods vehicles
Choose self-drive or driver service
Cancel bookings
Review drivers
Driver
Accept or reject booking requests
View assigned rides
View customer reviews
Rate customers
Admin
Manage vehicle records
Process bookings
Monitor system activity
Generate reports
